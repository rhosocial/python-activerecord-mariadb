Parameterize the search string in `match_against()`. The factory in `functions/fulltext.py` built the `MATCH ... AGAINST` clause by interpolating `search_string` into an f-string and returning the result as a `RawSQLExpression` with no bound parameters, so an input containing a quote escaped the literal and reached the driver verbatim. The function now returns `MariaDBMatchAgainstExpression`, which the dialect already formats through a bound placeholder (`format_match_against`). That expression class, its dialect formatter, its unit tests and its protocol-conformance assertion all already existed and were simply not used by this entry point; no test called the factory, which is how the divergence went unnoticed.
