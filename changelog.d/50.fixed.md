Aligned the backend with core #108 `DataType` refactoring: column definitions now require `DataType` instances and are formatted via `data_type.to_sql(dialect)` instead of string concatenation. Removed the redundant `format_delete_statement` override (which referenced non-existent `DeleteExpression` attributes and was never exercised) in favor of the core generic formatter, which correctly handles `RETURNING` capability gating for MariaDB 10.5+.
