# 支持的版本

## MariaDB 版本支持

| MariaDB 版本 | 支持状态 | 备注 |
|-----------------|----------------|-------|
| 5.5.x | ❌ 已停止维护 | 不再支持 |
| 10.0.x | ❌ 已停止维护 | 不再支持 |
| 10.1.x | ❌ 已停止维护 | 不再支持 |
| 10.2.x | ✅ 支持 | 添加窗口函数、CTE、JSON 函数 |
| 10.3.x | ✅ 推荐 | 当前 LTS 系列，添加系统版本化表、序列 |
| 10.4.x | ✅ 推荐 | LTS 系列，添加 `INSTEAD OF` 触发器 |
| 10.5.x | ✅ 推荐 | LTS 系列，添加 RETURNING 子句 |
| 10.6.x | ✅ 支持 | LTS 系列，添加 EXPLAIN ANALYZE |
| 10.11.x | ✅ 推荐 | 当前 LTS，稳定且广泛部署 |
| 11.x | ✅ 支持 | 创新版本 |
| 12.x | ✅ 支持 | 最新的创新版本 |

> **重要提示**：此后端专为 MariaDB 数据库设计。方言行为与 MariaDB 的版本特定功能紧密耦合。**请勿将此后端与其他 MySQL 系列数据库一起使用**（包括 MySQL、Percona Server 或 Aurora）。虽然 MariaDB 与 MySQL 兼容，但其方言在重要方面存在差异（系统版本化表、序列、`RETURNING` 等）。与非 MariaDB 数据库一起使用可能会导致生成错误的 SQL 或出现意外行为。

## 版本功能边界

方言根据服务器版本（`MARIADB_VERSION_BOUNDARIES`）自动检测 MariaDB 功能：

| 功能 | 最低版本 |
|---------|-----------------|
| 窗口函数 / CTE | 10.2.0 |
| JSON 函数 | 10.2.3 |
| JSON 箭头运算符（`->>`） | 10.2.7 |
| INTERSECT / EXCEPT | 10.3.0 |
| 序列 | 10.3.0 |
| 系统版本化表 | 10.3.0 |
| `FOR UPDATE SKIP LOCKED` | 10.3.0 |
| RETURNING 子句 | 10.5.0 |
| EXPLAIN ANALYZE / FORMAT | 10.6.0 |
| `RENAME TABLE ... IF EXISTS` | 10.5.0 |

## Python 版本要求

| Python 版本 | 支持状态 | 备注 |
|----------------|----------------|-------|
| 3.8 | ✅ 支持 | |
| 3.9 | ✅ 支持 | |
| 3.10 | ✅ 支持 | |
| 3.11 | ✅ 支持 | |
| 3.12 | ✅ 支持 | |
| 3.13 | ✅ 支持 | 支持自由线程构建（3.13t） |
| 3.14 | ✅ 支持 | 支持自由线程构建（3.14t） |

**自由线程 Python**：从 Python 3.13 开始，提供无 GIL 的自由线程构建，即 `python3.13t`、`python3.14t` 等。此后端兼容自由线程 Python，尽管某些与线程相关的功能可能表现不同。

## 依赖要求

| 依赖 | 版本 | 备注 |
|------------|---------|-------|
| rhosocial-activerecord | >=1.0.0 | 核心库 |
| mariadb | >=2.0.0rc2 | MariaDB 驱动程序（唯一支持） |

⚠️ **重要提示**：此后端仅支持 `mariadb` Python 驱动程序。不支持其他驱动程序，如 mysql-connector-python 或 PyMySQL。
