# Project Overview: rhosocial-activerecord-mariadb

## Project Name
- **Repository Name**: python-activerecord-mariadb
- **Python Package Name**: rhosocial-activerecord-mariadb

## Project Purpose

This project is a MariaDB backend implementation for the `rhosocial-activerecord` Python package. It provides MariaDB database support with the elegant ActiveRecord pattern interface.

## Key Design Principles

1. **Backend Implementation**: Extends core ActiveRecord with MariaDB-specific features
2. **Driver**: Uses `mariadb` connector for database connectivity
3. **Namespace Package**: Integrates with the rhosocial namespace package architecture

## Current Status

This project is under active development. Key features implemented:

- Basic CRUD operations
- Connection management
- Transaction support
- Schema introspection
- MariaDB-specific data types

## Version Control and Changelog

This project adheres to the same version control, branching, commit message, and changelog management standards as the main `python-activerecord` project.
